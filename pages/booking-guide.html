01

行車安全、監視器與鑰匙

  1. 車高約 3 公尺。地下停車場、低雨遮、招牌及樹枝都要避開；高度不確定就停下查看，或改走其他路線。
  2. 車尾超出後輪，轉彎時會向外擺。慢速轉彎、倒車與靠邊時，多留車側與右後角的空間。
  3. 監視器由左至右：正後方、後方俯視、右後角。畫面只供輔助；看不清楚就停車下車確認，必要時請同行者在安全位置引導。
  4. 車頭駕駛艙前排 3 席、後排 3 席；行車時全員坐在合法座位並繫安全帶。客廳、餐桌與床鋪僅限停妥後使用。
  5. 鑰匙照片由左至右為車頭、後方車廂門、水箱蓋。車頭門鎖向車前轉為開鎖、向車後轉為鎖門；離車前逐一拉門確認。
  6. 人少時可把行李收在駕駛艙空位並固定，保留客廳走道。藍牙音樂：首頁 → 應用 → 藍牙電話 → 與手機配對。
官網車長約 5 公尺、車寬約 2 公尺；停車以實車完整輪廓為準，車尾不得妨礙車道、人行道或其他車輛。高山下坡等完整提醒請看上方四張安全卡。

02

車邊帳、側桌與上下車

  1. 先確認場地允許使用車邊帳、桌椅及戶外設備，再把車停穩。一般停車位請依現場公告，不向車位外展開設備。
  2. 車邊帳轉桿與兩根支架收在駕駛艙後排座位下方。把轉桿的勾子掛入帳篷上方環孔，緩慢旋轉展開。
  3. 展開到需要的範圍後，用隨車支架支撐並確認穩固；風大、天候不穩、無人看管或睡前收回。
  4. 車側小桌僅在場地允許、車輛停妥時使用。離開前收回桌面、車邊帳、支架及轉桿，檢查扣具。
  5. 把木紋折疊踏凳放在平整穩固的地面，完全展開後再踩。上車在入口地墊脫鞋；開車前收好踏凳並固定。
車邊帳不是抗風雨遮棚。不要用「只開一小段」取代場地許可；帳篷、桌椅、燈串與料理設備都要遵守現場規則。

03

補清水、柴油與尿素辨識

  1. 清水加水口是車身右側、標示 WATER 的圓形蓋。用水箱鑰匙開蓋，以隨車乾淨水管加入適合清水箱使用的水。
  2. 清水箱約 110 公升，先看室內水量表。補水時有人看顧，留意水位；完成後停止供水、收管並鎖回水箱蓋。
  3. 露營區：先詢問可用水龍頭與補水方式。非露營區：加柴油前先問加油站是否願意提供合適水源，沒有就換其他補水點。
  4. 不要把來路不明的洗車水或回收水當成清水。水管保持乾淨，車內清水也不要直接當飲用水。
  5. 車子使用柴油，油箱在右側副駕駛側。把車頭鑰匙交給加油站人員，清楚說「柴油加滿」。
  6. 藍色蓋是尿素／AdBlue 系統，不能加水或汽油。柴油口、尿素口與清水口完全不同；不確定先拍照聯絡我們。
曾有把清水加進尿素箱造成車輛故障的案例。請讓加油站人員處理柴油加油；租客只在確認 WATER 標示後補清水。

04

露營區接電與發電機

  1. 充電線、水管與發電機備用油桶在左後方收納箱；白色兩孔插頭是露營車充電插頭。
  2. 露營區接電：先確認營區電壓、插座與負載限制。把延長線完全展開，保持插接處乾燥，再連接白色插頭與營區電源。
  3. 同一顆白色插頭也可接發電機 AC 插座。先拔除負載，再依面板 1 → 2 → 3 → 4 操作：冷車拉出 CHOKE、紅色開關 ON、拉啟動繩、穩定後才接電。
  4. 冷車啟動後，依交車示範把 CHOKE 阻風門推回。停機前先拔掉充電插頭，再將紅色開關切至 STOP。
  5. 發電機使用 92 無鉛汽油，與車用柴油分開。加油前必須停機並冷卻，使用隨車油桶分次慢加，不超過油箱允許上限；禁止加油槍直接對發電機灌油。
  6. 非露營區先確認允許充電設備、噪音與排氣條件。發電機排氣不能朝向車門、窗戶或其他車輛；有異味、漏油或一氧化碳警報立即停機、離開並聯絡我們。
僅在車輛停妥、確認符合原廠通風及排氣淨距後使用。不可在車廂、帳篷或封閉艙內運轉；打開艙門不代表通風已足夠。不確定現場配置時先不要啟動，拍照聯絡我們；行車前停機。

05

電量面板、燈、水泵與充電速度

  1. 車廂入口右側面板：左邊圓錶是清水量，中間螢幕是電池庫侖計，下排是設備開關。
  2. 從左起前四顆控制不同區域燈，第二顆為車外燈；第五顆是冰箱。用水前開啟「水泵／WATER PUMP」，用完或離車前關閉。
  3. 行車時關掉不需要的燈與水泵，冰箱可保持開啟。開車前檢查冰箱門及所有櫃門扣具。
  4. 剛交車、已校正時先看百分比與 Ah，滿電設定約 800Ah。多次充放電後百分比可能偏移，搭配面板旁電壓對照表與變化趨勢判讀。
  5. A 是淨電流：正數為淨充電，負數為淨耗電；W 是即時功率。即使接著電，冷氣等設備耗電較大時也可能顯示負數。
  6. 調整充電速度：打開面板下方最小櫃門，找到右下藍色旋鈕。營區供電有限或跳電時，先降低負載，再調低充電電流並觀察 A 數。
  7. 冷氣耗電大，盡早接電，避免電量低於 10%；吹風機與冷氣避免同時使用。現場電壓參考：13.5V 約 90% 以上、13.4V 約 80%、13.3V 約 70%、13.2V 約 60%。
電壓受充電與負載影響，對照表僅為操作參考。不要只用某一瞬間數字判定精確剩餘電量；顯示異常時拍下面板與設備狀態聯絡我們。

06

收納位置、冰箱與影音設備

看投影機、Type-C 轉 HDMI 與喇叭 AUX 接線圖解 →

  1. 入口旁長櫃：露營桌與露營椅。拿取後保持走道淨空，用完清潔並放回原位。
  2. 上方櫃由右側開始：Switch、線材與投影固定配件；其他櫃放露營布、野餐墊、燈串，以及棉被、床單與枕頭套。
  3. 冰箱上方櫃：野餐籃、藍牙喇叭、投影機、腳架及吹風機等。備品依當次交車清單為準。
  4. 冰箱上層冷凍、下層冷藏。開啟面板冰箱電源，食品固定收好，每次關門確認扣緊。車上目前沒有微波爐。
  5. 投影機先固定於腳架，再接 HDMI 訊源，例如 Switch。手機 Type-C 轉接需支援影像輸出，串流平台也可能限制播放；聲音依設備選擇 HDMI 或藍牙喇叭。
  6. 電子設備及燈串避免淋雨；每次拿完東西將櫃門壓回並扣緊，出發前巡查所有櫃門。
車上附的小枕頭可依需求搭配自備枕頭。高耗電料理設備請先詢問；不要自行接電鍋、電磁爐或氣炸鍋。

07

馬桶、分解液與污物箱

  1. 停妥車輛後，打開廁所燈，將馬桶轉到方便使用的位置。依交車示範扳開馬桶下方閥門，確認中央落口打開後使用。
  2. 使用後沖洗，將閥門扳回關閉，蓋好馬桶蓋。不要把濕紙巾、衛生棉、塑膠或其他異物丟進去。
  3. 每次清空污物箱後重新加入分解液。影片示範約 100–200 mL；實際依隨車藥劑標籤、濃度與交車指示用量，不是每次如廁都加。
  4. 清空前先關閉馬桶閥門。打開入口旁低處白色檢修門，提起固定扣，將污物箱平穩抽出。不要硬拉卡住的污物箱。
  5. 只能到管理方允許的污物處理／化學馬桶排放點清倒。旋出排污管、開蓋，依箱體指示傾倒並清洗，再蓋緊、裝回並確認固定扣卡好。
污物不得倒在路面、草地、雨水溝或一般水槽。公廁不一定接受化學馬桶污物，必須先取得管理方同意；分解液有使用限制時依排放點規定。

08

淋浴、備品與窗簾

  1. 先確認清水量，打開水泵，再開水龍頭。浴室龍頭可抽出作為蓮蓬頭，調整冷熱水後先試溫再淋浴。
  2. 使用短時間、間歇式沖洗：先淋濕、關水清潔、再沖淨。有營區浴室時優先使用，節省車上清水。
  3. 熱水未出、溫度異常或水泵持續運轉時，先關水及水泵，再拍照聯絡我們；不要拆改瓦斯或電線。
  4. 浴室上方櫃有浴巾與免洗牙刷等備品，用完關緊櫃門。淋浴後擦乾積水、保持通風，離車前關水泵。
  5. 窗簾按住灰色扣鈕後輕移：上方是遮光簾，下方是紗窗。雙手扶著操作，不拉扯簾面；開車前將窗戶關閉鎖好。
清水箱約 110 公升，不適合長時間連續洗澡。熱水與瓦斯設備以交車示範為準，未熟悉前先詢問。

09

餐桌變床與固定上舖

  1. 停好車、拉妥手煞車後再變床。移開桌上物品，將椅墊及靠背先放旁邊，保持桌腳周圍沒有雜物。
  2. 桌面可以前後左右移動，先調到不會卡住兩側座椅的位置。
  3. 按住桌腳升降釋放開關，雙手控制桌面緩慢向下壓，直到與兩側床板支撐面同高。手指避開升降與夾合處。
  4. 確認桌面與支撐穩固後，把左右座墊移到中間，細長墊補中央間隙，再把靠背墊拼到兩側，鋪成平整床面。
  5. 上方固定床可直接使用。還原餐桌時反向收好椅墊、扶住桌面並依交車示範升回定位；不要強拉或站在桌面上。
床鋪僅供停車時使用。行車時任何人都不能留在床、客廳或餐桌區；開車前把桌面與椅墊還原並確認固定。

10

跳電排查與出發／還車檢查

  1. 電力中斷先關閉吹風機、冷氣等高耗電設備，確認電池電量及營區電源，不要反覆強行重啟。
  2. 若為逆變器保護跳脫，依交車示範打開車廂右側座位下蓋，找到銀色逆變器側邊的 0／1 開關，切至 0，再切回 1。只操作外部開關，不碰接線或端子。
  3. 重啟後逐一開回必要設備；再次跳電、聞到焦味、發熱或有異音，立即停用並聯絡我們。蓋板裝回，保持散熱空間。
  4. 每次出發：收妥車邊帳、支架、側桌、踏凳、水管與延長線；拔除營區電源，鎖好艙門、窗戶、冰箱與櫃門。
  5. 確認全員回到駕駛艙繫安全帶、行李固定、車底與四周無障礙，再慢慢離開。
  6. 還車前：帶走私人物品與垃圾，餐具和裝備清潔歸位，依約加滿柴油，提前確認還車時間與地點；設備異常或損壞先告知。
旅途中需要協助：先安全停車，拍下整體位置、面板數字與異常狀態，傳 LINE 或 WhatsApp；緊急危險先離開現場並求助。
