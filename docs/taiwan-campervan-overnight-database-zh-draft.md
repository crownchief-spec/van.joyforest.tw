## 這份資料庫要解決什麼

這不是「哪裡有停車格」，也不是「合法露營區全部列一遍」。客人要看到的是：**開 JoyForest 露營車去這裡，真的會有一個值得記住的晚上。**

目前先留下 42 個高潛力地點：

- **21 個正規／管理型住宿點（50%）**：能補水、接電、洗澡、泡湯或安心展開露營設備。
- **21 個自由車宿與旅行點（50%）**：海景、夜景、溫泉、親子公園、漁港或政府車泊專區。
- 每個地點都至少具備以下證據之一：JoyForest 實拍、政府／業者明確資訊、近期車友實住文章、實際露營車影片、穩定的高評價。
- 一般停車場「能停」只是最低門檻；沒有漂亮景觀、好玩的內容或實住口碑，就不收錄。

## 評分標準

| 項目 | 判斷方式 |
|---|---|
| 體驗感 | 看海、日出、夜景、溫泉、森林、湖景或很強的親子設施 |
| 真實性 | 有 JoyForest／客人實拍，或可追溯的車宿、露營車實住紀錄 |
| 露營車適合度 | 約長 5m、寬 2m、高 3m 的自走車能否進出、轉彎、停妥 |
| 旅行價值 | 不是只睡一晚，附近還有吃、玩、泡湯、單車、海岸或地方文化 |
| 目前狀態 | 優先用 2026 官方、業者及近期實住資訊；舊文章只能當線索 |

### 證據等級

- **A**：官方或業者明寫可露營車／車宿，或政府設置車泊專區。
- **B**：JoyForest／客人實際使用，或多筆可信車友實住紀錄。
- **C**：體驗非常好，也有汽車營位／車泊線索，但約 3m 高自走車仍須先問。

一般停車場若未禁止，可作車內休息；但側帳、桌椅、爐具、投影與露營設備不拿出車外。完整展開請回到正規露營區。

## 這次刪掉的「只是能停」候選

以下不再為了湊縣市數量放進推薦：普通市區公園、沒有景觀或實住證據的停車場、只有一篇舊文章卻無近期狀態的點、固定式露營車住宿但不接受外來露營車的業者。

也不收錄明確不適合者：

- 武陵農場未訂住宿／露營者在管制期夜間淨場。
- 雲嘉南部分遊客中心、海濱停車場明文禁止露營與炊煮，只作白天景點。
- 阿里山國家森林遊樂區內不任意露營。
- 花蓮鹽寮休息區有開放時間與禁止露營公告。
- 加路蘭遊憩區自 2026-02-23 至 2026-12-31 全區施工封閉，本版先以金樽漁港海岸車宿替代。
- 太魯閣合流露營區現況受道路與災後工程影響。
- 清水那方營運與設施現況未明。
- 高雄輕風椰林明寫不接受車宿。
- 地下停車場、有雨棚限高或入口低於 3m 的場所。

## 下一輪只做兩件事

### 1. 補齊仍不夠強的縣市

基隆、新竹市、雲林本身可選點較少，已保留真正有實住證據的外木山、南寮、椬梧。嘉義市本身不硬塞普通停車場，直接與嘉義縣大埔、阿里山一起呈現。接下來優先找：桃園第二個真正精彩車泊點、臺中第二個非后里路線、臺東金崙或知本第二個溫泉車宿、花蓮海洋露營區最新外來車規則。

### 2. 一次完成營主確認

對 C 級地點一次問完：

1. 是否接受外來自走式露營車並睡車內？
2. 車約長 5m、寬 2m、高 3m，入口、樹枝、雨棚、坡道與迴轉是否安全？
3. 水、電、浴室、廁所、灰水、垃圾如何使用？
4. 車外可否開側帳、桌椅與瓦斯爐？
5. 最新費用、入住時間、訂金、取消、寵物、安靜時段？
6. 是否同意 JoyForest 放名稱、官方連結與業者授權照片？
